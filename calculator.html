파괴신 · 강림 원정대 · 4턴~70턴 전체 로테이션

딜 계산 — 전체 턴 예측 (2라운드 딜만 계산)

캐릭터 스탯을 바꾸면 70턴 전체 표가 실시간으로 재계산돼. 버프/디버프 타이밍(누가 언제 뭘 쓰는지, 지속시간 규칙)은 전부 고정이고, 스탯 숫자만 바꾸는 용도.

사용법
1. 아래 "캐릭터 스탯 입력"에서 각 캐릭터의 물공/치확/치피/약공/피증 및 반지 세팅을 입력하세요. 게임 내 캐릭터 상세 화면과 동일한 값을 넣으면 됩니다.
2. 값을 바꾸면 아래 표가 자동으로 재계산됩니다. 스킬 순서와 버프 타이밍은 고정이며, 스탯 숫자만 바꾸는 용도입니다.
3. 스탯 화면을 캡처해서 이미지로 올리면(여러 장 가능) 자동으로 값을 채워줍니다. 자동 인식 후에는 값이 맞는지 한 번 확인해주세요.
4. 입력이 끝나면 "내 계정에 저장" 버튼을 눌러야 다음에 접속했을 때도 값이 유지됩니다. 저장하지 않으면 새로고침 시 값이 초기화됩니다.

캐릭터 스탯 입력

스탯 화면 캡처 이미지를 여기로 드래그하거나, 클릭해서 선택하세요 (여러 장 가능)

깡공564+15%는 고정. 잠재%는 전원 공유(현재 18+15+15+15=63%).

턴별 데미지 (4턴~70턴, 83행동+보스평타11회 도트)

전체 헤브니아 파이 세인 샤오 비스킷
턴캐릭터행동둘다미적용크리만약공만크리+약공
합계 - - - -
※ 방어계수·취약%·피증%·버프 지속시간 규칙(캐스팅턴+대상 평타N회, 자기캐스팅 즉시/다음타 적용, 비스킷버프 평타전용 등)과 캐릭터별 실측 검증 보정계수는 고정값으로 내장되어 있습니다. 스탯 입력값만 바꿔서 재계산하세요.
